# Precifica Freela — Demo (tier Grátis)

Demonstração pública contendo **somente a versão gratuita** da calculadora de precificação para freelancers no Brasil.

## O que tem nesta demo
- Calculadora 100% gratuita e ilimitada (taxa/hora mínima, preço por projeto, receita estimada, capacidade usada)
- Presets "Iniciante" e "Estabelecido"
- FAQ
- 100% estático (HTML/CSS/JS puro): roda off-line, nada sai do navegador

## Como rodar
Abra o `index.html` no navegador, ou sirva localmente:
```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Versão completa
A versão completa inclui o plano Pro (orçamentos ilimitados, exportar PDF, múltiplos clientes, lembrete de reajuste anual). Em breve.

> Resultado estimado para fins educativos — não é consultoria financeira/contábil.
